|总字数:962|阅读时长:3分钟|浏览量:

前言

高考完也是来泥🐔了。军训期间折腾了一下校园网，发现 Linux 相关的资料并不多，而且泥🐔官网的 jlu drcom 根本用不了，搞了半天才吃上泥🐔校园有线网 100MB/s 的速度。

本人的电脑环境是 Arch Linux + NetworkManager。

网线购买

泥🐔大学城二公寓的网口在门框上，非常高。我靠窗，买的 10m 绿联六类千兆网线（其实 8m 就够了，奈何京东 8m 比 10m 还贵，恼），不靠窗的室友买 5m 就够用。

Drcom 认证客户端

此时因为没有认证，打开任何网页都会跳到 drcom 的下载页面，而泥🐔官网的 Linux 客户端年久失修，根本用不了。

好在 GitHub 上有不少泥🐔学生写的客户端，这里使用其中之一：dr-jlu-linux。

配置方法蛮简单的，确保安装了 git 和 make：

然后把 Login/main.cpp 第五行的 <username> 换成你的校园邮箱 @ 前面的部分，<password> 换成校园邮箱密码；第六行的 xxxxxxxxxxxx 换成你的网卡 MAC 地址（去掉冒号），eg: a1b2c3d4e5f6。

此后每次运行 make run 即可（改了邮箱或密码，就编辑文件后执行 make build && make run）。

总结

泥🐔校园有线网非常迅速，多线程能把我千兆网线跑满。我折腾了快 20min 才弄好，此教程旨在分享经历，让 Linux 用户少走弯路。
