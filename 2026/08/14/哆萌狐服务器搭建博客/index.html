萌狐云服务器搭建博客命令整合

发布于 2026-08-14 · 182 字 · 约 1 分钟
#Linux #教程 #博客 #hexo
安装 nvm :
BASH
curl -o- https://raw.githubusercontent.com/nvm-sh/nvm/v0.39.5/install.sh | bash
安装 npm :
BASH
nvm install --lts
安装 hexo :
BASH
npm install hexo-cli -g
创建个人博客:
BASH
hexo init [你想要的博客名]
切换到博客根目录:
BASH
cd [你想要的博客名]
安装所需包
BASH
npm install
安装 buttferfly 主题:
TEXT
npm install hexo-theme-butterfly
创建你的第一篇文章:
BASH
hexo new [文章名]

此时文章会被放在 source/_posts 目录中，以后随便找个markdown编辑器写

生产静态文件
BASH
hexo generate

此时网页文件会在 public/ 下生成

运行测试
BASH
hexo server
这里放一下 hexo 和 butterfly 的网页
TEXT
https://hexo.io
https://butterfly.js.org
