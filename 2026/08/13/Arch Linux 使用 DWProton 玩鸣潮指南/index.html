Arch Linux 使用 Lutris + DWProton 运行鸣潮 | Linux 游戏折腾记录

发表于2026-08-13|更新于2026-09-12
|总字数:919|阅读时长:3分钟|浏览量:

1.环境准备

1.1 安装 Lutris

这是我使用的游戏管理器，非常推荐

其他发行版用户的话可前往 官网，提供了很多发行版的下载方法

1.2 安装 DWProton

这是对”anime games”优化的 proton 版本，其他几个 proton 会被鸣潮的反作弊拦截导致无法进入游戏

其他发行版用户可前往 Releases 下载tar.xz文件，然后解压到自己能找到的地方

使用 ProtonPlus 进行管理当然也是可以的

2.安装鸣潮

如果是在 Windows 上安装过并且不想再在 Linux 上安装的话可以跳过，毕竟 Linux 是可以读取 Windows 的 ntfs 文件的

方案一 ww-manager

支持增量更新，服务器切换，预下载，文件校验等功能

其他发行版可以使用 uv 安装

至于 uv 的安装方法见下

然后在命令行输入 ww 即可看到食用方法

方案二 wuwa-downloader

其他发行版

然后终端

即可食用

开始配置

工具准备好了，该开始使用了

1.1 修改文件防掉线

国际服

修改Wuthering Waves/Client/Binaries/Win64/ThirdParty/KrPcSdk_Global/KRSDKRes/KRSDK.bin中的KR_ChannelId为209

国服

修改Wuthering Waves/Client/Binaries/Win64/ThirdParty/KrPcSdk_Mainland/KRSDKRes/KRSDKConfig.json中的KR_ChannelId为209

这个基本每次更新后都要修改，因为会被覆盖

1.2 配置 Lutris + DWProton

启动 Lutris，点击 左上角三点 → Preferences → Runners → 下滑找到Wine → 齿轮图形的设置
开启 Advanced
然后 Wine version，此时如果出现了dwproton，直接选择即可
若没有 则下面的 Custom Wine executable，找到刚刚解压出的 dwproton，AUR 安装的请选择 /usr/share/steam/compatibilitytools.d/dwproton/proton

1.3 鸣潮，启动！

回到 Lutris 首页 → 左上角「+」 → Install a Windows game from an executable → 怎么填都行 → Install → Install → Continue → 选择鸣潮的 Wuthering Waves.exe → Install

此时鸣潮应该就运行起来了

进入鸣潮后注意先选择退出游戏，而非直接删掉窗口，否则会让 Lutris 以为安装失败了

退出后就安装完成了

Lutris 中应该会出现一个鸣潮的启动方式 （若没有则点左边栏的 Windows）

鼠标放到上面，右键 → Configure →

  • Game options → Executable → 选择 Wuthering Waves.exe && Arguments 填入 -SkipSplash # 跳过库洛Logo用的
  • Runner options 确定所使用的 Wine 为 dwproton
  • System options → Game execution → 添加 Environment variables：
Key Value
DXVK_ASYNC 1
DXVK_CONFIG dxgi.maxFrameLatency=1
DXVK_STATE_CACHE 1
FCITX5_ENABLE_WAYLAND 1
GTK_IM_MODULE fcitx
MESA_SHADER_CACHE_DISABLE 1
PROTON_ENABLE_NVAPI 1
QT_AUTO_SCREEN_SCALE_FACTOR 0
QT_IM_MODULE fcitx
WINEDLLOVERRIDES mscoree,mshtml=,winemenubuilder.exe=d
WINEESYNC 1
WINEFSYNC 1
XMODIFIERS @im=fcitx
__GL_SHADER_DISK_CACHE 1
__GL_SHADER_DISK_CACHE_SIZE 10737415240
上面是我的配置，可能会有多余的，如果不用fcitx5或者没配置也能正常玩可以不配置

然后就可以愉快的玩鸣潮了

如果想要性能检测的话可以装个 mangohud
