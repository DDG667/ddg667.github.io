Arch Linux 软件推荐

Arch Linux 软件推荐

以下是为 Arch Linux 用户精选的一系列实用软件，涵盖了日常使用、开发、多媒体创作、系统工具等多个方面。所有软件均可通过官方仓库或 AUR 轻松安装。

🖥️ 窗口管理器与桌面环境

Hyprland

一款基于 Wayland 的动态平铺窗口管理器，以出色的视觉效果和高度可定制性著称。它支持动画、圆角、模糊等现代特性，适合追求极致效率和美观的用户。

🖥️ 终端模拟器

Alacritty

一款使用 OpenGL 渲染的终端模拟器，以速度和简洁为目标。它支持丰富的配置选项，且与 tmux、neovim 等工具配合流畅。

📝 文本编辑器

Neovide

Neovim 的图形化前端，利用 Skia 渲染引擎实现了流畅的动画和现代化的界面。它保留了 Neovim 的全部功能，并添加了鼠标支持、字体连字等特性。

📂 文件管理

Dolphin

KDE 项目开发的轻量级文件管理器，界面直观且功能强大，支持标签页、拆分视图、预览面板和版本控制集成。

Ark

KDE 的归档工具，支持常见压缩格式（zip、tar、7z 等），与 Dolphin 无缝集成，可方便地解压和创建压缩包。

🌐 浏览器

Firefox Developer Edition

Mozilla 为开发者打造的 Firefox 版本，内置最新的开发者工具，并支持 CSS 网格布局调试、JavaScript 调试器等高级功能。

📚 办公与笔记

Obsidian

一款强大的知识库和笔记应用，基于本地 Markdown 文件，支持双向链接、图谱视图和丰富的插件系统，适合构建个人知识网络。

GeoGebra

动态数学软件，集几何、代数、表格、绘图、统计和微积分于一体，是数学教学和学习的利器。

🎵 多媒体播放

VLC

全能的媒体播放器，支持几乎所有音频和视频格式，内置解码器，无需额外安装编解码器。

mpv

极简而强大的命令行视频播放器，基于 MPlayer 和 mplayer2，支持 GPU 加速和脚本扩展，适合追求轻量和高自定义的用户。

🎨 多媒体编辑与创作

Blender

开源的 3D 创作套件，支持建模、雕刻、纹理、渲染、动画、视频编辑和游戏制作等全流程，功能媲美商业软件。

Shotcut

免费、开源的跨平台视频编辑器，支持多种格式和分辨率，拥有丰富的滤镜和转场效果，界面简洁易用。

GIMP

GNU 图像处理程序，功能类似于 Photoshop，支持图层、滤镜、画笔和多种图像格式，是平面设计和照片修图的强大工具。

Helio

模块化音乐工作站，专注于旋律创作和编辑，提供直观的钢琴卷帘和节奏编辑器，适合制作电子音乐和学习乐理。

⬇️ 下载工具

Motrix

一款简洁美观的下载管理器，支持 HTTP、FTP、BitTorrent 和 Magnet 链接，基于 aria2，可同时管理多个任务。

⌨️ 输入法

Fcitx5

新一代输入法框架，支持拼音、五笔、仓颉等多种输入法引擎，与 Wayland 兼容良好，配置灵活。

📊 系统监控

Mission Center

一款现代化的系统监控工具，界面仿 Windows 任务管理器，可实时查看 CPU、内存、磁盘、网络和进程信息。

📱 兼容层与虚拟化

Waydroid

在 Wayland 会话中运行 Android 应用的容器方案，基于 LXC 和 Anbox 技术，可无缝集成 Android 应用到 Linux 桌面。

Wine

Windows 应用兼容层，允许在 Linux 上运行 Windows 程序。WineHQ 是 Wine 的官方版本，提供最全面的兼容性支持。

以上软件均经过精心挑选，覆盖了 Arch Linux 用户可能涉及的多个领域。你可以根据自己的需求选择安装，享受 Arch 带来的自由与高效。
