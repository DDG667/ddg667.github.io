Arch Linux 安装并破解 DaVinci Resolve Studio 21.1.1

发表于2026-10-08|更新于2026-10-08
|总字数:1.9k|阅读时长:7分钟|浏览量:

后期悲

剧情高考议论文，念念不忘三段式。
拍摄调光均「一流」，竖屏放大再裁切。

本文环境：Arch Linux (x86_64)、NVIDIA 显卡、AUR helper (paru)。

起因

学院办班级微电影大赛，负责后期。实觉 Kdenlive 之不足，转投 DaVinci Resolve Studio（下称 DRS）。

愿 Kdenlive 越做越好；也希望哪天有money买Studio授权 (2000 CNY+）。

一、安装

1.1 AUR 包选择

包名 说明
davinci-resolve-studio 上游原始归档
davinci-resolve-studio-aacfix 构建期注入 AAC 解码支持，推荐
davinci-resolve 免费版

BD（Blackmagic Design，DRS 背后的公司）给 Linux 版捆绑的 FFmpeg 库在编译时砍掉了 AAC 解码器，导入 AAC 音轨的素材会没声音。-aacfix 变体在构建期做两件事：

  • 用 e9patch 编译跳板（trampoline）并拼接进 bin/resolve；
  • 把捆绑的 4 个 FFmpeg 6.0.1 动态库替换成重编译的、启用 AAC 的 LGPL 构建。

代价是它的 makedepends 里带着 git、nasm、python-capstone、python-pyelftools，构建会明显偏慢（要现编 FFmpeg，还要给 700 MB 的二进制打补丁），别以为卡死了。

1.3 手动下载安装包

  1. 打开 DRS 下载页，点下载按钮。
  2. 选 DaVinci Resolve Studio 21 底下的 Linux。
  3. 弹出个人信息表单 —— 此处 BD 不做任何校验，随意填。
  4. 拿到 DaVinci_Resolve_Studio_21.1.1_Linux.zip（约 10 GB；装好后 /opt/resolve 会占约 19 GB）。

1.5 OpenCL：混合显卡机型注意

-aacfix 的依赖里有个虚拟包 opencl-driver，它自己不提供实现，得看你用哪块卡：

显卡 提供 opencl-driver 的包
NVIDIA opencl-nvidia
AMD rocm-opencl-runtime
Intel intel-compute-runtime

不装对应的那一个，DRS 启动时会直接不认 GPU。

2.1 好习惯，先备份

perl -pi 是就地重写：它按原 inode 打开并截断重写。712 MB 的文件在中途断电或 Ctrl-C，你手上就是一个废文件。备份不是可选项。

2.2 三条二进制补丁

三条补丁都是幂等的：改完的字节不再匹配原模式，重复执行什么也不会发生。所以”我不确定打没打过”的时候，直接再跑一遍即可。

补丁 3 用了 -0777，Perl 会把整个 712 MB 二进制 slurp 进内存再回写。机器内存吃紧的话先关掉别的程序。

四、Q&A

Q1：交付页面无法 N 卡加速导出

装 davinci-ffmpeg-encoder-plugin：

它是 DRS 的 IOPlugin，安装到 /opt/resolve/IOPlugins/ffmpeg_encoder_plugin.dvcp.bundle/Contents/Linux-x86-64/。重启 Resolve 后在交付页把编解码器设为 H.264 / H.265 / AV1，类型里就会出现带 ffmpeg 的 NVENC 选项。

Q2：升级或重装后失效

pacman 升级会覆盖 /opt/resolve/bin/resolve，三条补丁需重打一遍。/opt/resolve/.license/blackmagic.lic 一般会被保留（包里的 .license 是个空目录）。
